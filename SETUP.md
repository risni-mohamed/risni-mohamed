# Setup

1. Create or open the public GitHub repository:
   `risni-mohamed/risni-mohamed`

2. Upload all files and folders from this package to the repository root.

3. Commit the files to the `main` branch.

4. Open the repository **Actions** tab.

5. Select **Generate contribution snake** and click **Run workflow**.

6. Wait approximately one minute, then refresh your GitHub profile.

## Cache updates

After editing an SVG, increase the version in README.md:

- `banner.svg?v=1` → `banner.svg?v=2`
- `stats.svg?v=1` → `stats.svg?v=2`
